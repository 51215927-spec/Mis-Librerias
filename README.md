# Mis Librerías

Dos bibliotecas de C# para aplicaciones .NET 8: **Utilidades** facilita la entrada de datos y la presentación en consola; **DataBases** permite guardar objetos en CSV y consultar sus relaciones en memoria. Son independientes y no requieren paquetes externos.

Documentación:

- [Utilidades](Utilidades/README.md): entradas validadas, menús, colores, formato e historial de consola.
- [DataBases](DataBases/README.md): configuración de entidades, relaciones, archivos CSV y manejo de errores.
